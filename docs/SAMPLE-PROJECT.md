# An editable glass pavilion

Choose **Explore an editable sample house** on the opening screen, or **Projects → Open sample house** at any time. ATELIER first saves the current project, then opens a separate editable copy. If saving fails, it keeps the current workspace. Each opening makes a fresh copy; existing edits are not reset. Switch back through Projects. Projects remain local to this browser; export a JSON backup to move one between devices.

The sample is an original conceptual study inspired by Farnsworth House, not a measured reconstruction. It contains 24 named objects in five unlocked groups:

- **Envelope:** a raised 18 × 8 × 3.2 m glass pavilion with parametric slabs/mullions, plus an open porch floor and roof.
- **Structure:** eight individually editable columns.
- **Interior:** a timber service core and counter.
- **Terraces & steps:** a lower terrace and two short flights of steps.
- **Landscape:** two volumetric trees and a person for scale.

Everything uses the existing geometry engine and project format. There are no baked screenshots, protected meshes or separate demo-only tools. The lower terrace starts selected. Try its **Push / pull**, **Stretch**, **Scale**, **Copy** or **Array** tools, or edit exact dimensions in the inspector. Undo restores each change. Select the pavilion to explore **Floors / Glass / Volume** views and its architectural parameters. Select column groups, turn layers on/off, rotate the view, add a section, study the sun, or place the walkthrough camera on the porch. The sample can also be exported to OBJ or prepared for AR.

When AI is configured and funded, natural requests work through the same checked modeling engine—for example, asking to widen the lower terrace, change column color, place yourself between named objects, or add a volume. No example sentence is required syntax. Ambiguous or unsupported design requests still need clarification; the sample does not make arbitrary geometry or live voice understanding verified.

Loading, direct editing and USDZ/OBJ preparation do not consume AI credits. Text/voice requests do. Cloud tests verify solid geometry, editable dimensions/undo, independent project copies, reload and preservation of the previous project. Actual phone AR tracking and live voice still need device testing.
