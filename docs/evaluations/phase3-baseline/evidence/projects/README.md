# Inspectable final projects

These six files use ATELIER's ordinary `serializeProject` format. They contain the final committed geometry from A2 (canopy), B2 (bench), C2 (mechanical assembly), D2 (lantern), E2 (array) and F2 (wedge recovery), including the unchanged protected sample objects. Component and group data were checked for exact equality after parsing each exported file.

They are geometry-only exports. They do not claim to contain the browser conversation or Undo stack; full saved sessions and browser storage, including actual reload/Undo/Redo evidence, are retained in the raw archive. Import into a separate project to inspect them without replacing your own design.

No R project is presented as a committed result: its correct repaired candidate was blocked and is preserved only as an explicitly provisional snapshot in the archive.
